# User Manual

## Responden terautentikasi

1. Masuk lalu buka **Survei Saya**.
2. Pilih survei eligible, baca tujuan/privacy notice dan tenggat.
3. Mulai pengisian. Gunakan navigasi bagian; progress dihitung dari item yang dapat dijawab.
4. Sistem autosave setelah jeda singkat. Jangan tutup tab ketika status masih menyimpan. Bila jaringan gagal, draft lokal dipertahankan dan dapat dipulihkan.
5. Lengkapi item wajib, buka tinjauan, lalu konfirmasi kirim. Submit final tidak dapat diedit.
6. Simpan kode receipt. Klik ganda/retry aman dan menghasilkan penyelesaian yang sama.

## Responden external

Buka link invitation hanya dari sumber resmi. Token yang expired atau revoked tidak dapat digunakan. Setujui consent sebelum mulai. Jangan meneruskan link/token. Bila link bermasalah, hubungi admin tanpa mengirim screenshot yang memuat token lengkap.

## Privasi dan riwayat

Mode anonymous memisahkan isi response dari identitas/partisipasi. Mode confidential memakai pemetaan terpisah dengan akses terbatas. Riwayat yang tersedia hanya informasi partisipasi yang diizinkan; pimpinan tidak melihat jawaban individual. Hindari menulis nama, nomor identitas, kontak, atau rahasia pada komentar bebas.

## Dashboard pimpinan

Pilih filter unit/period/group dalam scope. Dashboard menampilkan aggregate released, timestamp, response rate, score, limitations, dan suppression. Nilai disembunyikan berarti sample di bawah threshold—bukan nol. Chart selalu memiliki tabel/ringkasan pendukung. Drill-down dibatasi ke level agregat yang diizinkan.

## AI dan tindak lanjut

Output berlabel AI adalah draft, mencantumkan model/source scope/timestamp/review status, dan tidak menggantikan statistik. Gunakan hanya hasil approved. PIC tindak lanjut memperbarui root cause, plan, progress, evidence, lalu submit verification; revisi harus ditindaklanjuti sebelum submit ulang.

## Accessibility dan bantuan

Gunakan link **Lewati ke konten utama**, Tab/Shift+Tab, Enter/Space, Escape pada dialog, serta zoom browser. Form memakai label, error summary, live autosave status, table summary, dan mobile reflow. Bila terjadi error, catat waktu, halaman, dan request ID jika ada; jangan mengirim password, token, cookie, atau jawaban survei kepada helpdesk.
